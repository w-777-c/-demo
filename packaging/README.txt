铁境竞技场 / Iron Arena
Windows x64 免安装版

1.1.0 / 远征与联机

启动
1. 将整个压缩包解压到有写入权限的文件夹。
2. 双击 IronArena.exe 开始游戏，无需安装 Java。
3. 首屏可以直接游客试玩，也可以注册本地账号保存战绩。

离线远征
选择铁卫、狂刃或灵术师，挑战十关或无尽模式。
每次有效行动获得25能量，100能量可释放职业大招。
敌方意图显示下一次反击。第3、6、9关为精英，第10关为守关者。
胜利后选择一项战后奖励，再进入下一场。大招能量每场重置。
控制台入口保留经典玩法；职业与奖励选择在桌面版中提供。

局域网对战
1. 两名玩家在各自电脑上打开游戏，点击右上方“联机对战”。
2. 一人选择端口并点击“创建房间”，复制地址栏的地址给另一人。
3. 另一人输入房主的局域网IP和端口，例如192.168.1.20:8765，点击“连接”。
4. 双方填写昵称，点击“入席”和“准备”，即可轮流出招。
5. 房主关闭联机窗口会结束房间；只关闭窗口中的席位不会关闭服务。
如 Windows 防火墙询问，允许游戏附带的 Java 在专用网络上通信。
多网卡或VPN环境下，可改用房主电脑连接同一局域网的IPv4地址。
同一台电脑测试时，将游戏复制成两个目录，避免共用存档锁。
联机采用统一属性和五种基础技能；职业大招与战后奖励属于离线远征。
支持旁观、认输、双方同意再战及30秒断线恢复。没有公网匹配或房间列表。
互联网对战需要另外部署服务或配置网络连通性，本包不会自动穿透路由器。

存档
账号与已结算战绩保存在 IronArena.exe 旁的 data 文件夹。
移动游戏时一起保留 data，即可携带已有账号与战绩。
更新版本时，先关闭游戏，再将旧版本的 data 复制到新版本目录。
当前版本不支持恢复未完成的一局；正常关闭窗口会提示结算。

文件说明
IronArena.exe：游戏启动程序。
app：桌面游戏、JSON依赖、内置联机服务和启动配置。
runtime：随游戏附带的 Java 运行环境，许可说明见 runtime/legal。
data：首次启动后保存账号、战绩和运行锁。
data/host-端口.log：创建房间时记录联机服务启动日志。
JAVA-RUNTIME.txt：所用 Java 运行环境的版本信息。

请保留整个游戏目录，app 与 runtime 均为运行所需文件。
此版本为 Windows 10/11 x64 桌面应用，不适用于手机或 macOS。
