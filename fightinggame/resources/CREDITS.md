# Iron Arena / Crimson Theatre Assets

The interface follows a vintage fantasy theatre direction: crimson curtains,
antique gold ornament, teal glass, illustrated fighters and ticket-shaped controls.
The supplied visual reference is used for art direction only. Its character art,
logos, screenshots and music are not embedded in this project.

## Original project assets

- Character artwork and scenery: original Java2D paths in `ui/GameArt.java`.
  Three role silhouettes with enemy palette variants, rendered and cached at runtime.
- Audio: original synthesized PCM WAV files generated by `tools/GenerateAudio.java`.
  `overture.wav` is the lobby waltz; `battle.wav` is the combat arrangement.
  Remaining files are short interaction and battle effects.
- Windows icon: a Lucide crown on the project's crimson background.

These assets are not image-generation output or third-party game assets.

## Regeneration

Normal builds use checked-in assets and need no Node.js or asset downloads.
To regenerate audio, run `java tools/GenerateAudio.java` with JDK 17+.
To regenerate icon PNGs and the Windows ICO, install the existing multiplayer
dependencies (`npm ci --prefix multiplayer`), install `@resvg/resvg-js` under
`build/ui-tools` (`npm install --prefix build/ui-tools --no-package-lock --no-save @resvg/resvg-js`),
then run `node tools/prepare-ui-assets.cjs`.
