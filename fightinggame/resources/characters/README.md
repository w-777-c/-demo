# 角色立绘资源规范

局内战斗和角色图鉴会优先读取以下透明 PNG；文件缺失时自动回退到 `GameArt.java` 的代码立绘：

| 文件 | 对应角色样式 |
| --- | --- |
| `actor-0.png` | 铁卫 / 战士基础形象 |
| `actor-1.png` | 狂刃 / 刺客基础形象 |
| `actor-2.png` | 灵术师 / 法师基础形象 |
| `actor-3.png` | 银幕守卫 / 战士敌影 |
| `actor-4.png` | 绯刃使 / 刺客敌影 |
| `actor-5.png` | 星辉术士 / 法师敌影 |

建议生成规格为 2:3 竖图，透明背景，角色完整站立并保留脚部，推荐 1024x1536 或更高。程序会在加载时等比例缩放到统一的 480x720 逻辑画布，因此不需要手工裁切。

素材提示词应描述原创角色、服装、武器、职业色和动作姿态；参考图只用于构图、卡面排版和配色方向，不直接复制原作角色、Logo、水印或文字。
